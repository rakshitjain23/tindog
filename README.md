## 🌟 Overview

**TinDog** is a playful, responsive landing page created while learning **HTML, CSS, and Bootstrap**.  
The website represents a fictional app that helps dogs meet and connect — just like Tinder, but for pets!

This project was built to practice:

- Bootstrap layout system  
- Responsive UI design  
- Using components like cards, navbars, buttons, and carousels  
- Structuring a clean frontend webpage  

---

## 🛠 Technologies Used

- **HTML5**  
- **CSS3**  
- **Bootstrap 5**  
- **Google Fonts**  
- **Font Awesome Icons**  
- **GitHub Pages** (Deployment)

---

## ✨ Key Features

- Fully responsive layout  
- Attractive hero section  
- Pricing plans styled with Bootstrap cards  
- Testimonials carousel
